# 设置页信息架构重排

状态：主人已确认（2026-11-27）——按第 2 节分组；设置页自带导航；D 一次性替换全站共享组件；第 4 节前端项除「推送网关状态」外全做；需后端的 Passkey、控制面运维参数、免打扰、开机自启本轮只出接口设计，备份与导出暂不做。
原始盘点：`.oil-ui/control-language/audit/settings-audit-{inventory,backend,scattered}.md`（本地，不入库）。

## 1. 现状问题（按影响排序）

1. **没有自己的导航。** 27 个分区全部挂在侧栏「更多」里（`components/layout/more-entries.ts`），分三组且混排；手机上换分区要先开抽屉。设置页本身只有页头和内容区（`SettingsPage.tsx:1348-1366`）。
2. **同一设置多处可改，控件还不一样。** 语言：外观（分段）+ 关于（下拉）。更换服务器：关于（移动壳）+ 桌面应用（桌面壳）。明暗：外观 + 侧栏按钮 + 命令面板。
3. **东西放错地方。** 「新对话默认对象」在身份页（`IdentitySettings.tsx:247-295`），输入框预测在 Agent 组；「选区快捷动作」是个人右键菜单偏好，却在 Agent 组；助手记忆在「记忆」页里，而该页自述不作用于全局助手；预算只在统计页（`BudgetCard.tsx`）。
4. **该合的没合。** Git 身份 / GitHub 分两页；Provider / Runner 同构各写一份；公开分享 / Artifacts 两条目都带 Artifacts；技能 / 提示词与上下文 / 命令与规则 本质都是 Markdown 文件管理，拆成三页且名字互相重叠。
5. **过短与过长并存。** 输入框（2 个开关）、Git 身份（1 个表单）各占一条；子 agent 945 行、`SettingsPage.tsx` 1413 行塞了 9 个分区实现。
6. **两套组件。** 只有通知页用 D 的 `workbench.tsx`，其余是 `Card/ListRow/Toggle`；开关、行高、标题、分组间距都不一致。`LeadIcon` 重复 4 份，设置行（标签 + 说明 + 开关）各页自拼。
7. **「身份」一词撞车。** 设备、Git 身份、GitHub 身份、身份与头像四处都在说身份。

## 2. 目标结构

原则：按「这项设置影响谁」分组——**我和这台设备 / 助手与 Agent / 工作区资源 / 分享与关于**；一个设置只有一个家；一页讲一件事。

| 分组 | 新分区（路由 id） | 内容来源 | 变化 |
|---|---|---|---|
| 个人 | 账户与设备 `account` | 我的头像（identity）、设备与配对、更换服务器、退出登录 | 合并；更换服务器/退出登录从「关于」「桌面应用」收归此处 |
| 个人 | 外观 `appearance` | 明暗、主题色、壁纸、App 图标、语言 | 语言成为唯一入口，关于页下拉删除 |
| 个人 | 输入与快捷键 `input` | 输入框预测、新对话默认对象、选区快捷动作、**发送键**、**快捷键一览** | 新分区；加粗为新增 |
| 个人 | 通知与预算 `notifications` | 现有通知 + **预算上限与告警** | 预算复用 `/stats/budget`，统计页保留查看 |
| 个人 | 桌面应用 `desktop`（仅桌面壳） | 更新、托盘、全局快捷键、令牌存储、**重置窗口与布局** | 去掉重复的更换服务器 |
| 助手与 Agent | 全局助手 `assistant` | 助手身份、模型、提示词、联网、MCP、研究、Computer、助手记忆 | 助手相关三处合一 |
| 助手与 Agent | 模型与角色 `agent-models` | 模型角色、角色头像、Agent 默认身份、**默认思考档位** | 原 roles + identity 的 agent 部分 |
| 助手与 Agent | 子 agent `agent-subagents` | 不变 | — |
| 助手与 Agent | 技能与指令 `agent-instructions` | 技能、提示词与上下文、命令与规则 | 三页合一，分节 |
| 助手与 Agent | 扩展与工具 `agent-extensions` | 不变 | — |
| 助手与 Agent | 记忆 `agent-memory` | Hindsight 记忆 | 移出助手记忆 |
| 助手与 Agent | 配置文件 `agent-config` | 原「高级」 | 改名 |
| 工作区 | 自动化 `automations` | 不变 | 从「概览」组移入 |
| 工作区 | 算力 `compute` | Provider + Runner | 合并，统一「新建 → 一次性令牌」流程 |
| 工作区 | 控制面 `server` | **空闲回收、数据保留、磁盘上限**（原只在 `orynd.yaml`） | 新分区（主人已确认）；随后端接口一起上线，见 `settings-backend-apis.md` 第 2 节 |
| 工作区 | 密钥 `secrets` | 不变 | — |
| 工作区 | SSH 主机 `ssh` | 原 agent-ssh | 改归工作区 |
| 工作区 | Git 与 GitHub `git` | Git 身份 + GitHub | 合并 |
| 工作区 | 浏览器 Profile `browser-profiles` | 不变 | — |
| 其它 | 分享与 Artifacts `sharing` | 公开分享、自动发布、Artifacts 授权 | 合并 |
| 其它 | 关于 `about` | 版本、协调宿主、移动壳信息 | 只留信息 |

27 个分区 → 20 个；控制面随后端上线后为 21 个。旧路由全部重定向到新位置（推送、文档、命令面板里可能存着旧链接）。

## 3. 导航

- **桌面宽度：** 设置页自带左侧分组导航（约 200px）+ 右侧内容（688px 纸面），顶部一个设置内搜索。侧栏「更多」只保留概览类页面和一个「设置」入口。
- **手机：** `/settings` 是分组列表首页（D 的分组列表样式），点进分区后页头有返回；不再依赖抽屉。
- **注册表：** 分区 id、分组、图标、显示条件（`desktopOnly` 等）收进一份注册表，路由、设置导航、命令面板共用（替代 `App.tsx` 的 `SETTINGS` 与 `more-entries.ts` 的设置部分）。

## 5. 执行顺序

1. **全站共享组件换成 D**（原地改，调用方 API 不变，一次覆盖全站）：
   - `Button` 圆角 10、`IconButton` 9；颜色沿用墨色主按钮，高度不变（工具栏里与 32px 图标钮对齐）。
   - `TextInput` / `TextArea` 换成 D 输入框（圆角 11、半透明底、「提亮浮起」聚焦），删掉 `workbench` 里重复的 `TextField` / `TextAreaField`。
   - `Toggle` 换成 D 开关（墨色、`role=switch`），删掉 `workbench` 的 `Switch`。
   - `Field` 换成 L2 标题（13/550 正文色），长说明仍在控件下方；`FormField` 保留给要「可选」标记和行内短说明的表单。
   - `Checkbox` 圆角 5。`Dialog`（32）、`Menu` / 浮层（18）、`Card`（18）保持现有圆角：生产里本来就比 D 稿大，且主人已在试点里看过；只改主人明确认可的数值。
   - `Select`：所有调用方改用自绘下拉（触屏回落原生），之后删除原生 `Select`。
2. **设置骨架：** 分区注册表（路由、设置导航、命令面板共用）、设置页内导航与搜索、手机分组首页、旧路由重定向；把 `SettingsPage.tsx` 里内联的 9 个分区拆成独立文件。
3. **逐组迁移：** 个人 / 助手与 Agent / 工作区 / 其它 四组并行，各组合并、移动并改用 `Group` / `GroupRow` / `Toggle`，测试随迁移更新。
4. **前端新增设置：** 预算、默认思考档位、发送键、快捷键一览、重置布局、设置内搜索。
5. **接口设计（只出文档）：** Passkey 管理、控制面运维参数、通知免打扰、桌面开机自启。

每一步的验收：`npm run check`、受影响分区的测试文件、mock 环境下浅色 / 深色 / 390px 截图。
