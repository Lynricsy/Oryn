# Oryn Web 界面设计说明（M3.5 重设计）

## 北极星

对话是摊在桌面上的一份工作记录。结论留在纸面，过程退到页边，需要你的地方才有颜色。

后续开发的约束与验证流程见 [`web-guidelines.md`](web-guidelines.md)。

## 调性

安静、精致、密度中高、轻、严肃度中性。三个旋钮：Variance 3 / Motion 3 / Density 7（工具型界面的起点）。

## 材质四层

|层|用在|做法|
|---|---|---|
|L0 桌面|`AppShell` 根|`--bg` + 两处极淡的主题色晕染（`.shell-wash`），让玻璃有东西可透|
|L1 纸面|对话区、右面板、首页、设置的主容器|`.sheet`：`--panel` 底、1px `--line`、圆角 32（`--r-xl`）、`--sh-sm`|
|L2 玻璃|线程页头、输入坞、回到底部、菜单、弹层、命令菜单、toast、折叠屏双段时的侧栏抽屉、登录卡|`.glass`：半透明 + `backdrop-filter`（放在 `::before` 上）+ 内高光 + `--sh-md`|
|内嵌井|代码块、输入框、终端、量表轨道|`--inset` 底|

对话框面板用不透明 `--panel` + `--sh-xl`，遮罩 `--scrim` + 2px 模糊。玻璃的模糊放在伪元素上：宿主不成为 backdrop root，也不成为 fixed 后代的包含块，嵌套玻璃（页头里的菜单、托盘里的命令菜单）才模糊得出来。`prefers-reduced-transparency` 与不支持 `backdrop-filter` 时回退为不透明 `--panel`。

## 颜色规则

- 主按钮是墨色（`ink`），三家标杆（Conductor、Linear、Amp）都这样做；强调色只给「需要你」的东西：未读点、`awaiting_input`、发送、提交回答、批准计划、焦点环、链接、选中滑块。
- 绿/黄/红只表达成功/警告/错误。
- 组件里不出现颜色字面量；全站颜色只从 `web/src/index.css` 的令牌出。例外：外观设置的 6 个色块、favicon。

### 选色依据

- 强调色默认青碧（teal，oklch 色相 205），刻意避开红（25）、琥珀（78）、绿（152）三条语义色带，让「需要你」与「出错/警告/成功」在色相上不混淆。旧版橙色 `--brand`（42）与 `--bad`（27）、`--caution`（75）相邻，正是要修的问题。
- 中性色取冷灰蓝（色相 235，随主题色预设微调），区别于 Amp 默认主题的带绿米白/青黑，避免撞脸。
- `--text-faint` 提到 L=0.49（浅色）/0.63（深色），小字对比度达到 4.5:1；更淡的 `--text-ghost` 只用于非文字的装饰与禁用。
- 主题色预设：青碧、钴蓝、堇紫、莓红、狐橙、石墨，每个预设只改 `--tint-h/--accent-h/--accent-c`（狐橙、石墨另调明度）。

## 令牌用途

|令牌|用途|
|---|---|
|`rounded`(4)|Kbd、行内徽标（Badge）、复选框|
|`rounded-xs`(6)|项目徽标、标题图标、头像方块、行内代码|
|`rounded-sm`(9)|树行、小 chip、计数胶囊；28px 以上的项目徽标|
|`rounded-md`(12)|按钮、输入框、标签页、菜单项、Callout|
|`rounded-lg`(18)|纸面内的卡片、工具卡、代码块、表格外框、侧栏行、菜单/弹层/toast、用户气泡|
|`rounded-xl`(32)|纸面、输入坞托盘、对话框、命令菜单|
|`rounded-2xl`(36)|侧栏玻璃、首页输入卡、登录卡|
|`text-2xs`(11px)|最小字号；替代全部 `text-[11px]` 与 `text-[10px]`|
|`text-xs`(12)/`text-sm`(13)|界面正文；转录散文在 `.md` 里单独设 14.5px/1.7|
|`shadow-xs/sm/md/lg/xl`|按钮与选中行 / 纸面 / 玻璃浮层 / 菜单弹层 toast / 对话框与抽屉|

**角形**：带圆角的表面一律 `corner-shape: superellipse(1.6)`（`index.css` 的 `@layer base` 全局规则），半径随之整体加大一档（同半径下超椭圆更「收」）。这是主人在 6 种 demo（圆角 / squircle / 超椭圆 × 两档半径）里选定的「h」。正圆与胶囊（`rounded-full` 及其 `after:` 等变体、`.tv-spin`）保持 `round`；OrbBead、Ring 是 SVG，不受影响。Chromium 139+ 原生支持；Safari、Firefox 不认 `corner-shape`，自动退回普通圆角。

**同心**：外层圆角里套内层表面时，贴近外角的内层半径 ≈ 外层半径 − 间距。对话框 32 − 内边距 20 → 输入框 12；菜单 18 − 4 → 菜单项 12；输入坞托盘 32 里第一节带色调底时取 `calc(var(--r-xl) - 1px)`；右面板纸面 32 − 8 内的卡片取 18（与全站卡片同一令牌，卡片不贴角，24 并不更协调）。

**屏幕圆角同心（M7）**：移动壳报告物理屏幕四角半径与原生容器加在 WebView 外的 inset（系统栏 + 刘海 + 软键盘），`lib/device-corners.ts` 算出视口四角的同心半径 = max(0, 屏幕半径 − 该角相邻两边 inset 的较大者)，写到根元素 `--device-r-tl/tr/bl/br`（浏览器与桌面恒为 0）。贴着屏幕边缘的浮层用 `index.css` 的不分层类 `.dc-tl/tr/bl/br`，对应角取 max(自身令牌 `--dc-r`, 视口角半径 − 与边缘的间距 `--dc-gap`)：平板 / 宽屏的左侧玻璃侧栏与折叠屏双段时的悬浮抽屉左两角（间距 8）、手机下沉式侧栏打开时的内容卡片四角（间距 0，屏幕圆角为 0 时取 2xl 令牌，关闭时归 0）、手机输入坞托盘下两角（12）、手机底部弹层对话框下两角（0，平板起居中弹窗不适用）、最上一张 toast 右上角与最下一条连接错误右下角（12）、宽屏最右纸面右两角（8）。不贴边的表面不变；变量为 0 时公式退回令牌，视觉与以前完全相同。

非 Tailwind 的 CSS/JS（`tool-render.css`、`markdown.css`、`CodeEditor.tsx`、`xterm.ts`）只引用原始变量 `--r-*`、`--sans`、`--mono`、`--sh-*`、`--ease`。

## 字体

- Mona Sans（GitHub 开源可变字体）：开发者语境，数字清晰。
- 思源黑体（Noto Sans SC Variable）：用户要求内置中文字体，按 unicode-range 分片按需下载（包解压约 4.9MB）。
- 等宽：JetBrains Mono（主人指定）+ Symbols Nerd Font Mono。后者只覆盖私有区码点（`unicode-range: U+E000-F8FF, U+F0000-FFFFD`），只有页面出现 Nerd 字形（omp 标题卡图标、终端提示符）时才下载 1.2MB 的 woff2；效果等同整包 JetBrains Mono Nerd Font，体积更小。字体文件与 MIT 许可在 `web/src/assets/fonts/`。

## 动效

|处|做法|
|---|---|
|主操作反馈|所有 `Button` `active:scale-[0.98]`，150ms；发送钮 `active:scale-95`|
|状态切换来路|右面板标签页用一块会滑动的选中底板（`left/width` 180ms）；菜单、弹层、命令菜单、对话框、toast 进入用 `.pop-in`；抽屉从所在侧滑入 260ms，手机下沉式侧栏的内容卡片同样 260ms 平移（拖动时跟手）；左右栏列收起/展开同一套 260ms 收窄 + 淡入淡出；其余退出不做动画|
|获得焦点|输入托盘上移 2px、投影加深，底部亮起主题色光；不画焦点描边|
|首次出场|只有首页：状态珠、标题、输入卡依次上移 8px 淡入，间隔 60ms，仅首次挂载|
|记忆点|orb 状态珠：启动中 1.2s 旋转弧；就绪且 agent 工作时光晕 2.4s 呼吸；冻结/停机/失败静止。工具状态节点由转圈变勾时勾号画出 180ms|

转录消息、列表行、悬停不做入场动画。`prefers-reduced-motion` 时全部动画与过渡压到 1ms。

## 方向选择（Step 1）

三个方向各做一张真实的线程页首屏（`.dev/design/explore/{a,b,c}.html`，不入库）：A「晴」层叠纸面 + 玻璃、B「夜」座舱仪表、C「暖」温润手作。

主人的选择：「A 和 C 各有优势；C 的侧栏、工具、表格等对话内部组件更有质感；A 胜在没有 C 那样过分凸起（发送钮）的绘画感；A 整体不错但三栏都偏粗糙」。于是做了拼合稿 D「晴·手作」：

- **保留 A**：令牌与冷灰蓝中性色、主题色预设、桌面晕染、玻璃页头与整块玻璃输入坞、平面墨色主按钮与平面 accent 发送钮。
- **移植 C**：三栏同为纸面；侧栏分组图标、项目方形彩色徽标、fork 树状引导线、细描边计数胶囊；工具调用改为带类别色图标方块的圆角卡行（取代 A 的竖线过程轨）；思考行、编号方块列表、圆角表格、描边行内代码、回合脚注胶囊、助手回合头像；右面板带图标的规格胶囊与着色曲线的内嵌井行。
- **故意不搬**：上亮下暗内高光、发送钮彩色投影、3D 球体头像、用户气泡着色、暖米色与 Figtree 字体（这些就是「凸起 / 绘画感」的来源，或违反「颜色只给需要你的东西」）。
- 实测修正：`--glass` 由 72% 降到 58%（否则透不出下方内容）；浅色 `--syn-number`、`--syn-title` 加深；accent 与成功色作文字时混入正文色（`--accent-ink`、`--good-ink`）以达 4.5:1。

**D 稿是锁定的视觉基线**（`.dev/design/explore/d.html`，截图 `shots/d-light.png`）。工具调用卡、输入坞、右侧栏的结构与细节以它为准；独立评审的建议与 D 稿冲突时先问主人，不直接改。第 1 轮评审后曾把工具卡降成灰度行、去掉右面板描边与着色曲线，上下文分段又因只读缓存而默认不显示，主人指出比 D 稿粗糙，已按 D 稿恢复。

同轮追加的功能（主人选择）：omp 标题卡（`<图标> <代码>: <标题>`）解析为图标方块 + 代码徽标；项目图标默认采用首个线程标题卡的图标、可手选覆盖；agent 头像存服务端；侧栏显示所有运行中线程的当前意图（取自工具调用的 `i` 参数）；改动标签新改动点、`~N` 统计、「与分支比较」。

## 放弃的做法

- **折叠过程只看结论**（标杆 Amp/Linear 的 `› 17 tool calls`）：与「对话区按 omp 信息量全量展示」的既有约束冲突；改为全量展示，工具调用是安静的圆角卡行。
- **diff 行号列**：信息增量小，挤占窄屏宽度。
- **自定义色相滑块**：6 个固定预设足够，任意色相难以同时保证明暗两套对比度。
- **主题云同步**：明暗与主题色只存本机浏览器（agent 头像例外，存服务端）。
