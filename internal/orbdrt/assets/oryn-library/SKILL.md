# Oryn 文件库

全局助手（Oryn 首页的助手对话）有一个文件库。orb 里的文件存进去之后，所有助手对话都能读到，用户也能在文件库面板里预览、下载。

## 存入文件

```sh
oryn library put <文件> [--name <库内文件名>]
```

- `<文件>` 是 orb 里的一个普通文件（相对路径按当前目录解析），单个文件上限 100 MiB。
- 存入后的文件状态为「库内共享」，来源记为本线程；命令打印文件库 id、文件名与大小（`--json` 输出完整记录）。
- 同一个文件再 put 一次会得到一条新记录，不会覆盖旧的。
- 只能存文件，不能存目录：多个文件先打包（例如 `tar czf out.tgz dir/`）再存。

## 何时使用

- 用户说「放进文件库」「交给助手」「存一份给全局助手看」时。
- 产出物需要在别的对话里继续使用，而不是只留在本 orb 的工作区里时。

不要把密钥、令牌、`.env` 之类的敏感文件存进文件库。
